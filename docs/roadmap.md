# Engineering Learning Roadmap

This roadmap is the source of truth for the daily learning automation.

## Phase 1 — Backend Foundations

### Day 001 — HTTP Fundamentals

- **Category:** Backend Fundamentals
- **Difficulty:** Beginner
- **Objective:** Understand how clients and servers communicate using HTTP requests and responses.

### Day 002 — REST API Design

- **Category:** APIs
- **Difficulty:** Beginner
- **Objective:** Understand REST-style resource design and how APIs expose application functionality.

### Day 003 — WebSockets

- **Category:** Realtime Communication
- **Difficulty:** Beginner
- **Objective:** Understand when persistent bidirectional connections are useful.

### Day 004 — gRPC Fundamentals

- **Category:** Service Communication
- **Difficulty:** Intermediate
- **Objective:** Understand RPC-style service communication and protocol buffers.

### Day 005 — PostgreSQL Basics

- **Category:** Databases
- **Difficulty:** Beginner
- **Objective:** Understand relational databases, tables, rows, columns, and SQL basics.

### Day 006 — Indexes in Databases

- **Category:** Databases
- **Difficulty:** Intermediate
- **Objective:** Understand why indexes speed up reads but add write/storage overhead.

### Day 007 — Redis as a Cache

- **Category:** Caching
- **Difficulty:** Beginner
- **Objective:** Understand how Redis is used to reduce database load and improve latency.

### Day 008 — Message Queues

- **Category:** Event-Driven Systems
- **Difficulty:** Intermediate
- **Objective:** Understand how queues decouple producers and consumers.

### Day 009 — Authentication vs Authorization

- **Category:** Security Basics
- **Difficulty:** Beginner
- **Objective:** Understand the difference between proving identity and checking permissions.

### Day 010 — API Rate Limiting

- **Category:** API Reliability
- **Difficulty:** Intermediate
- **Objective:** Understand how systems protect APIs from abuse and overload.

## Phase 2 — Containers and Platform

### Day 011 — Docker Fundamentals

- **Category:** Containers
- **Difficulty:** Beginner
- **Objective:** Understand containers, images, Dockerfiles, and local development workflows.

### Day 012 — Docker Compose

- **Category:** Local Development
- **Difficulty:** Beginner
- **Objective:** Understand how to run multi-container applications locally.

### Day 013 — Kubernetes Basics

- **Category:** Kubernetes
- **Difficulty:** Beginner
- **Objective:** Understand what Kubernetes does and why teams use it.

### Day 014 — Kubernetes Pods and Deployments

- **Category:** Kubernetes
- **Difficulty:** Intermediate
- **Objective:** Understand how Kubernetes runs and manages application workloads.

### Day 015 — CI/CD Fundamentals

- **Category:** Software Delivery
- **Difficulty:** Beginner
- **Objective:** Understand how teams automate build, test, and deployment workflows.

## Phase 3 — Reliability and Observability

### Day 016 — Observability Fundamentals

- **Category:** Observability
- **Difficulty:** Beginner
- **Objective:** Understand logs, metrics, traces, and why production systems need observability.

### Day 017 — Distributed Tracing

- **Category:** Observability
- **Difficulty:** Intermediate
- **Objective:** Understand how traces follow a request across multiple services.

### Day 018 — Service Level Objectives

- **Category:** Reliability
- **Difficulty:** Intermediate
- **Objective:** Understand how teams define reliability targets using SLIs, SLOs, and error budgets.

## Phase 4 — System Design and Production

### Day 019 — Load Balancing

- **Category:** System Design
- **Difficulty:** Intermediate
- **Objective:** Understand how traffic is distributed across multiple backend instances.

### Day 020 — Incident Response Basics

- **Category:** Production Engineering
- **Difficulty:** Intermediate
- **Objective:** Understand how engineering teams respond to production issues.
