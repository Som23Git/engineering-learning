## Daily Notes

Notes are stored in the `daily/` directory.

## Human-in-the-loop

Each note includes sections for:

- My Understanding
- Mistakes I Made
- Questions I Still Have

These sections are intentionally left blank so I can add my own learning after reading the lesson.
